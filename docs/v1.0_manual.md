## 1. 项目是什么

```text
SSVEP 脑电（4 类）
    → MNE 预处理 → CCA 解码
    → 三层防抖
    → queue.Queue
    → 50 Hz 机器人控制
    → CoppeliaSim Ant 六足机器人
```

4 个指令：

| Event ID | 频率 | 指令 | 机器人动作 |
|---|---:|---|---|
| 1 | 8.0 Hz | 前进 | `forward` |
| 6 | 13.0 Hz | 左转 | `turn_left` |
| 11 | 10.2 Hz | 右转 | `turn_right` |
| 16 | 15.2 Hz | 停止 | `stop` / 站立退出 |

## 2. 第一次打开项目

### 2.1 用 VS Code 打开

```powershell
cd D:\bci-quadruped-project
code .
```

建议安装 Python / Jupyter 插件，选择解释器：

```text
D:\Anaconda3\envs\bci-quadruped\python.exe
```

### 2.2 打开 CoppeliaSim 场景

1. 启动 **CoppeliaSim 4.7 EDU**；
2. 菜单 `File → Open Scene`；
3. 选择：

```text
D:\bci-quadruped-project\scenes\my_robot_debugged.ttt
```

4. 确认窗口标题能看到 `my_robot_debugged`；
5. 保持仿真停止（不要手动点 Start，脚本会自己启动 stepping）。

> 不要打开 `my_robot_before_debug.ttt` 作为日常工作场景；它是调试前备份，shape 仍是 dynamic。

## 4. 启动机器人（Stage 2）

### 4.1 只读检查：先确认 18 个关节

```powershell
python src\step2_robot_control.py --inspect
```

期望：

```text
[OK] 18 个关节路径
[inspect] JOINT_PATHS complete: 6 legs x 3 = 18 handles.
[inspect] total: 23 joints
```

`parsed mapping` 里出现 `MISSING` 是正常的：Ant 的关节名不含腿编号，以 `JOINT_PATHS mapping` 为准。

### 4.2 只站立

```powershell
python src\step2_robot_control.py --stand-only
```

按 `Ctrl+C` 结束。正常姿态：

```text
本体 z = 0.0768
六足端 z ≈ -0.0006
18 个关节 Kinematic
```

### 4.3 向前走 5 步

```powershell
python src\step2_robot_control.py --walk-steps 5
```

实测：

```text
x: -0.503 → -0.707
前进约 0.204 m
z 保持 0.077
结束回到 STAND_POSE
```

> “5 步”指 5 个完整步态周期，不是 5 次 `sim.step()`。
>
> 本体是 Static，前进是 `sim.setObjectPosition()` 的视觉位移，不是物理摩擦推进。
> 只想原地迈步：

```powershell
python src\step2_robot_control.py --walk-steps 5 --walk-body-step 0
```

### 4.4 完整演示

```powershell
python src\step2_robot_control.py
```

顺序：

```text
stand 2 s → forward 3 s → turn_left 2 s → stand 1 s
```

右转版本：

```powershell
python src\step2_robot_control.py --turn-right
```

### 4.5 单关节测试 / 解除封印

```powershell
# FL joint1 在 ±45° 之间摆动
python src\step2_robot_control.py --test-motion

# 检查限位、依赖、dummy、IK target
python src\step2_robot_control.py --unseal
```

> 正常 Ant 的 `targetLeg1..6` 是 IK target dummy（`dummytype=5`、`linktype=5`）。
> `_prepare_kinematic_model()` 会在运行时把它们置 0，并在 `shutdown()` 恢复；
> 不要手动把整个模型设 Static 后就直接跑 forward。

## 6. 跑 Stage 3：闭环联调

### 6.1 不连 CoppeliaSim（推荐先跑）

```powershell
python src\step3_closed_loop.py --dry-run --max-seconds 20
```

只验证线程、队列、防抖和终端日志，不会动机器人。

### 6.2 真正驱动 Ant

```powershell
python src\step3_closed_loop.py
```

默认：

```text
--trial-interval        1.5 s
--max-seconds           90 s
--confidence-threshold  0.30
--window                5
--majority              3
--cooldown              1.5 s
--seed                  42
```

快速测试（每个 trial 0.5 s）：

```powershell
python src\step3_closed_loop.py --trial-interval 0.5 --max-seconds 25
```

终端应看到：

```text
[原始解码] 前进 (0.85) -> [防抖状态] 投票中（1/5，前进×1） -> [下发指令] —
[原始解码] 前进 (0.24) -> [防抖状态] 忽略（低置信度 0.24） -> [下发指令] —
[原始解码] 左转 (0.65) -> [防抖状态] 确认（左转 3/5） -> [下发指令] 左转
[机器人] 切换动作 -> 左转
```

### 6.3 停止逻辑

- 防抖确认 `stop` 后，consumer 调用 `controller.stop()` 平滑回站立；
- 然后 `shutdown()` 恢复 shape / IK target 属性；
- 如果一直没确认 stop，`--max-seconds` 到点也会安全退出并站立。

## 7. 怎么调整数据

### 7.1 换数据文件

默认读取：

```text
data/S1.mat
data/S2.mat
```

Stage 3 默认只读 S1：

```powershell
python src\step3_closed_loop.py --data D:\bci-quadruped-project\data\S2.mat
```

数据结构应为：

```text
(channels=64, samples=1500, targets=40, blocks=6)
```

先做数据体检：

```powershell
python tests\check_data.py
```

### 7.2 改标签 / 频率 / 时间窗

在 `src/step1_cca_decode.py` 中修改：

```python
LABELS = [1, 6, 11, 16]
FREQS  = [8.0, 13.0, 10.2, 15.2]
BANDPASS = (6.0, 16.0)
EPOCH_TMIN = 0.2
EPOCH_TMAX = 1.7
N_HARMONICS = 3
CCA_CHANNELS = ["PO7", "PO3", "POz", "PO4", "PO8", "O1", "Oz", "O2"]
```

注意：

- `LABELS` 与 `FREQS` 必须一一对应；
- 如果加入 15.2 Hz 以上频率，带通上限要相应放宽；
- 如果换通道，确认 `CH_NAMES` 的 64 通道顺序与新数据一致；
- 改标签后，同步修改 `src/step3_closed_loop.py` 的 `LABEL_TO_ACTION`。

### 7.3 改站立姿态

在 `src/step2_robot_control.py` 中：

```python
CAPTURE_STAND_POSE = True
STAND_POSE = {...}
```

两种方式：

1. **捕获**：保持 `CAPTURE_STAND_POSE=True`，在场景里手动摆好姿态，运行 `--stand-only`，复制终端打印的 6 组角度到 `STAND_POSE`；
2. **手填**：设 `CAPTURE_STAND_POSE=False`，直接改 `STAND_POSE`。

修改后必须重跑 `--stand-only` 验证，不要热改。

### 7.4 改步态参数

`src/step2_robot_control.py` 顶部：

```python
GAIT_FREQ = 1.2
YAW_SWING = 0.28
LIFT_AMOUNT = 0.15
KNEE_BEND = 0.10
LIFT_PHASE_OFFSET = 0.0
TURN_STRIDE_GAIN = 0.35
STOP_DURATION = 0.5
```

调参口诀：

| 现象 | 调整 |
|---|---|
| 走反 | `YAW_SWING` 取负 |
| 拖地 | 增大 `LIFT_AMOUNT` / `KNEE_BEND` |
| 抬太高/抽搐 | 减小 `LIFT_AMOUNT` / `KNEE_BEND` |
| 落地时仍在向前扫 | 调 `LIFT_PHASE_OFFSET`（试 ±π/2） |
| 转向太猛 | 减小 `TURN_STRIDE_GAIN` |
| 步频过快/过慢 | 调 `GAIT_FREQ` |

### 7.5 改三层防抖

`src/step3_closed_loop.py` 的 `Debouncer`：

```python
confidence_threshold = 0.30
window_size = 5
majority = 3
cooldown_s = 1.5
```

命令行覆盖：

```powershell
python src\step3_closed_loop.py `
  --confidence-threshold 0.35 `
  --window 5 `
  --majority 3 `
  --cooldown 2.0
```

含义：

- 阈值越高，越保守，误触发少但可能“叫不动”；
- 窗口越大，越稳但确认越慢；
- 冷却越长，动作越稳但切换越迟钝。

### 7.6 改模拟噪声

`src/step3_closed_loop.py` 的 `decode_one()`：

```python
if rng.random() < 0.15:   # 15% 低置信度
    confidence = rng.uniform(0.10, 0.29)

if rng.random() < 0.10:   # 10% 标签翻转
    ...
```

按需修改概率；改 `--seed` 可复现不同随机序列。

## 8. 场景、备份与恢复

| 文件 | 用途 |
|---|---|
| `scenes/my_robot_debugged.ttt` | 当前工作场景（z=0.0768） |
| `scenes/my_robot_debugged_walk_ok_20261108.ttt` | 5 步行走验证版备份 |
| `scenes/my_robot_before_debug.ttt` | 调试前备份（dynamic shape） |

备份：

```powershell
Copy-Item "scenes\my_robot_debugged.ttt" "scenes\my_robot_backup.ttt"
```

恢复：

1. CoppeliaSim 停止仿真；
2. `File → Open Scene` 重新加载；
3. 重新跑 `--inspect` 确认 18/18。

> 不要在仿真运行时保存场景，否则可能把临时 release 状态写进 `.ttt`。
> 如果 Python 被强杀，重载 `my_robot_debugged.ttt` 即可恢复。

## 9. 常见问题

### Q1. `--inspect` 18/18 但 `parsed mapping MISSING`

正常。Ant 的关节名是 `joint1Leg/joint2Leg/joint3Leg`，不含腿编号。
以 `JOINT_PATHS mapping` 的 18 个 `[OK]` 为准。

### Q2. 站立稳定，但 forward 腿不动

先跑：

```powershell
python src\step2_robot_control.py --unseal
python src\step2_robot_control.py --test-motion
```

- 如果 `actual` 跟 `cmd`，但 `tip` 不变：IK target 仍绑着腿；
- 如果 `actual` 也不动：关节模式/限位/依赖；
- 正常控制台应出现：

```text
[kinematic] static 57 shapes under /Ant; released 6 IK target dummy(s).
```

### Q3. 终端中文乱码

```powershell
chcp 65001
$env:PYTHONIOENCODING = "utf-8"
```

或直接使用 Windows Terminal。

### Q4. MNE 预处理 MemoryError

关闭多余程序后重试；数据只需预处理一次，不要在循环里反复 `build_raw`。
脚本已经把预处理放在 producer 启动阶段。

### Q5. 一直没收到 stop

正常：随机模拟可能长时间不确认 stop。用 `--max-seconds` 兜底，或缩短
`--trial-interval`/调低 majority 做快速测试。

### Q6. 5 步走完没有回到原点

正常。`--walk-steps` 用 `setObjectPosition()` 前进，不会自动回到起点；
重新加载场景即可复位。
